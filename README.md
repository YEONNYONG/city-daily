# 도시의 일상

프로젝트 문 세계관을 배경으로 한 웹 텍스트 시뮬레이션 게임의 견본입니다. 서류를 대조해 도장을 찍고, 찾아온 사람들과 이야기를 나눕니다.

- 플레이: https://yeonnyong.github.io/city-daily/

**비공식 비상업 2차 창작물입니다.** Project Moon과 관련이 없고, 승인받거나 후원받지 않았습니다. 원작의 세계관과 고유 명칭에 대한 권리는 Project Moon에 있습니다. 판매하지 않으며, 원작의 이미지·음성·클라이언트 자원을 사용하지 않습니다.

배경 그림은 NovelAI로 생성했습니다.

방문 수는 GoatCounter로 집계합니다. 쿠키를 쓰지 않고, 개인을 식별하는 정보는 저장하지 않습니다.
